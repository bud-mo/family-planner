## Version Objective

v0.6.0 is a **consolidation** release: it introduces no new user-facing features, but closes the findings raised by the architectural review (`docs/architecture-review.md`). Three workstreams:

1. **Security** — remove plaintext credential exposure via API and introduce optional protection on configuration routes.
2. **Runtime correctness** — fix SIGHUP reload inconsistencies, button handler initialization order, dead `last_push_at` parameter, and fields lost by the `/config` form.
3. **Robustness, cleanup, and documentation alignment** — explicit dependencies, cache eviction, icon sync, and especially bringing `architecture.md`, `README.md`, and `AGENTS.md` back in sync with the real code.

**Release closure criterion:** by the end of all phases, every finding in `docs/architecture-review.md` is either *resolved* or *deferred with a tracked rationale* in `docs/architecture.md` ("Known technical debt" section). At that point, `architecture-review.md` can be removed (Phase 6).

Constraints from previous versions remain valid. In particular for v0.6.0:

- **No functional regression**: the Home screen, artwork mode (B), return to planner (A), shutdown (D), web preview, and graceful reload must behave exactly as before, except where explicitly changed.

## Phase 1 — Security

**Goal:** no HTTP route exposes plaintext credentials without authentication; configuration routes can be protected; exposure on `0.0.0.0` without protection produces an explicit startup warning.

> **Design decision.** The server must stay reachable on LAN for headless RPi setups, so binding to `127.0.0.1` is not forced. Instead, adopt **optional Basic Auth** on sensitive routes plus **sanitized config download**. Alternative considered and rejected: default loopback bind (breaks documented headless use case). The alternative remains documented in `architecture.md` for users who prefer network isolation.

### 1.1 — Config schema: optional access credentials

In [config.py](../app/config.py#L14), extend `ServerConfig`:

```python
class ServerConfig(BaseModel):
    host: str = "0.0.0.0"
    port: int = 8080
    # Optional Basic Auth on /config and /api/config/* routes.
    # If both are None -> routes stay open (with startup warning if host is not loopback).
    auth_username: str | None = None
    auth_password: str | None = None
```

Update `config/default.yaml` with commented fields (default `null`), and treat `auth_password` as a credential: it must be scrubbed exactly like CalDAV passwords (see 1.3).

### 1.2 — Authentication dependency

Create `app/server/auth.py` with a reusable FastAPI dependency:

```python
from __future__ import annotations
import secrets
from fastapi import Depends, HTTPException, Request, status
from fastapi.security import HTTPBasic, HTTPBasicCredentials

_security = HTTPBasic(auto_error=False)

def require_config_auth(
    request: Request,
    credentials: HTTPBasicCredentials | None = Depends(_security),
) -> None:
    """Protect config routes when server.auth_* is configured.

    No-op if auth is not configured (open routes). Constant-time comparison.
    """
    cfg = request.app.state.config.server
    if not cfg.auth_username or not cfg.auth_password:
        return
    ok = (
        credentials is not None
        and secrets.compare_digest(credentials.username, cfg.auth_username)
        and secrets.compare_digest(credentials.password, cfg.auth_password)
    )
    if not ok:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Authentication required.",
            headers={"WWW-Authenticate": "Basic"},
        )
```

### 1.3 — Apply auth and sanitize config download

In [config.py routes](../app/server/routes/config.py):

- Add `dependencies=[Depends(require_config_auth)]` to **all** config router routes: `GET /config`, `POST /config`, `GET /api/config/download`, `POST /api/config/upload`, `POST /api/test-weather`, `POST /api/test-connection`. (Preview-only routes `/`, `/preview.png`, `/preview-eink.png` remain **open**: they show only calendar output, already free of credentials.)
- **`config_download`** ([config.py:257](../app/server/routes/config.py#L257)): stop serving the raw file. Generate a sanitized YAML on the fly that blanks all CalDAV `password` values plus `auth_password`, reusing `_safe_config_dict` logic:

```python
@router.get("/api/config/download")
async def config_download(request: Request) -> Response:
    config: AppConfig = request.app.state.config
    safe = _safe_config_dict(config)          # CalDAV passwords already blanked
    safe["server"]["auth_password"] = ""      # scrub access password too
    body = yaml.dump(safe, allow_unicode=True, sort_keys=False)
    return Response(
        content=body,
        media_type="application/x-yaml",
        headers={"Content-Disposition": 'attachment; filename="config.yaml"'},
    )
```

> Note: downloaded backups require re-entering passwords on restore. This is the right trade-off: no secret ever leaves the device via HTTP.

- Extend `_safe_config_dict` ([config.py:32](../app/server/routes/config.py#L32)) to also blank `data["server"]["auth_password"]`, so `GET /config` does not reveal the access password.

### 3.2 — Aggregator cache eviction (§4.7)

[aggregator.py:55](../app/calendar/aggregator.py#L55): cache keyed by `(start, end)` accumulates one entry/day. Add pruning of expired entries in `get_events`, under lock:

```python
def get_events(self, start, end):
    cache_key = (start, end)
    now = time.monotonic()
    with self._cache_lock:
        # Eviction: remove entries older than TTL
        expired = [k for k, (ts, _) in self._cache.items() if now - ts >= self._cache_ttl]
        for k in expired:
            del self._cache[k]
        entry = self._cache.get(cache_key)
        if entry is not None and now - entry[0] < self._cache_ttl:
            return entry[1]
    events = self._fetch_all(start, end)
    with self._cache_lock:
        self._cache[cache_key] = (time.monotonic(), events)
    return events
```

**Acceptance:** unit test with low `cache_ttl` verifies `_cache` does not grow beyond 1-2 entries after many calls with different keys and advanced time (monkeypatch `time.monotonic`).

**Acceptance:** `python -c "from app.renderer.icon_catalog import WEATHER_ICONS; print(sorted(WEATHER_ICONS))"` -> `['cloud', 'cloud-rain', 'snowflake', 'sun']`; asset generation scripts no longer produce unused weather icons.

### 3.4 — All-day events independent from longitude (§4.9)

### 1.2 — Authentication dependency

Create `app/server/auth.py` with a reusable FastAPI dependency:

```python
from __future__ import annotations
import secrets
from fastapi import Depends, HTTPException, Request, status
from fastapi.security import HTTPBasic, HTTPBasicCredentials

_security = HTTPBasic(auto_error=False)

def require_config_auth(
    request: Request,
    credentials: HTTPBasicCredentials | None = Depends(_security),
) -> None:
    """Protect config routes when server.auth_* is configured.

    No-op if auth is not configured (open routes). Constant-time comparison.
    """
    cfg = request.app.state.config.server
    if not cfg.auth_username or not cfg.auth_password:
        return
    ok = (
        credentials is not None
        and secrets.compare_digest(credentials.username, cfg.auth_username)
        and secrets.compare_digest(credentials.password, cfg.auth_password)
    )
    if not ok:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Authentication required.",
            headers={"WWW-Authenticate": "Basic"},
        )
```

```python
def get_events(self, start, end):
    cache_key = (start, end)
    now = time.monotonic()
    with self._cache_lock:
        # Eviction: remove entries older than TTL
        expired = [k for k, (ts, _) in self._cache.items() if now - ts >= self._cache_ttl]
        for k in expired:
            del self._cache[k]
        entry = self._cache.get(cache_key)
        if entry is not None and now - entry[0] < self._cache_ttl:
            return entry[1]
    events = self._fetch_all(start, end)
    with self._cache_lock:
        self._cache[cache_key] = (time.monotonic(), events)
    return events
```
