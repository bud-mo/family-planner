# Development Plan - Family Planner v0.5.0

> Version: 0.5.0
> Date: May 24, 2026
> References: `docs/architecture.md`, `docs/design.md`, `docs/0.4.0-devplan.md`

---

## Version Goal

v0.5.0 completes the architecture unification by removing Playwright from the runtime and adopting **`PillowEinkRenderer` as the single renderer** for both display types (HDMI and e-ink).

The three main issues that motivate this change compared to v0.4.0:

1. **5-view system removed.** The interface adopts a single Home screen (weather banner, mini-calendar, agenda list, footer). The `View` enum and its related navigation hierarchy are removed.
2. **`HdmiDisplay` refactored.** It no longer uses non-headless Chromium: the window is now a `pygame` SDL surface that directly receives the `PIL.Image` produced by `PillowEinkRenderer`, removing the `playwright` dependency for both display types.
3. **`NavigationState` simplified.** Fields `view`, `selected_date`, `selected_event_uid`, and `detail_scroll_offset` are replaced by `anchor_date` and `page_offset`; actions `in/out/up/down` become `prev/next/today/night`.

At the end of v0.5.0, the `playwright` binary is no longer a project dependency. `docs/architecture.md` and `docs/design.md` already describe the target state for this version; this dev plan documents the migration from the current code to that target.

## Invariant Constraints

Constraints from previous versions remain valid. In addition, for v0.5.0:

- `PillowEinkRenderer` is the **single rendering source** - `playwright` is never started or imported in normal mode
- `HdmiDisplay.run_blocking()` runs on the **main thread**; Uvicorn runs in a separate `threading.Thread(daemon=True)`
- `NavigationState` remains immutable; `navigate_*` methods return new instances
- `StateManager` is the **only** source of truth for `NavigationState` - no other object owns or independently copies state
- `render()` is the **only** place where layout `Rect`s are computed - `_draw_*` methods receive `Rect` as input and do not read global layout constants
- `WeatherData` is a placeholder in v0.5.0 - all fields are `None`; the weather banner shows only today's date
- `_GRID_*` constants and functions `_event_to_grid`, `_build_annual_months`, `_find_event_by_uid` remain in `data_builders.py` until the cleanup phase (Phase 8) to avoid blocking parallel development

## Phase 1 - NavigationState

**Goal:** `NavigationState` uses `anchor_date` and `page_offset` instead of `view` / `selected_date` / `selected_event_uid` / `detail_scroll_offset`. Navigation methods become `navigate_prev`, `navigate_next`, `navigate_today`, `toggle_night_mode`.

*No dependency - this phase is a prerequisite for Phases 3, 5, and 6.*

### 1.1 - Rewrite `app/renderer/state.py`

Remove:
- `View` enum and all its values
- Fields `view`, `selected_date`, `selected_event_uid`, `detail_scroll_offset`
- Methods `navigate_escape`, `navigate_enter`, `navigate_up`, `navigate_down`
- Helpers `_events_for_date`, `_select_adjacent_event`
- Imports `TYPE_CHECKING` / `CalendarEvent` (no longer needed)

New dataclass structure:

```python
@dataclass(frozen=True)
class NavigationState:
    anchor_date: date = field(default_factory=date.today)
    page_offset: int = 0
    night_mode: bool = False

    def navigate_next(self) -> NavigationState:
        """Advance by PAGE_DAYS days in the agenda list."""
        return replace(
            self,
            anchor_date=self.anchor_date + timedelta(days=PAGE_DAYS),
            page_offset=self.page_offset + 1,
        )

    def navigate_prev(self) -> NavigationState:
        """Go back by PAGE_DAYS days; never before today."""
        if self.page_offset <= 0:
            return self
        return replace(
            self,
            anchor_date=self.anchor_date - timedelta(days=PAGE_DAYS),
            page_offset=self.page_offset - 1,
        )

    def navigate_today(self) -> NavigationState:
        """Reset anchor_date to today and page_offset to zero."""
        return replace(self, anchor_date=date.today(), page_offset=0)

    def toggle_night_mode(self) -> NavigationState:
        """Toggle night mode (HDMI only)."""
        return replace(self, night_mode=not self.night_mode)
```

Add module constant:

```python
PAGE_DAYS: int = 7   # day step for navigate_next/navigate_prev
```

**Acceptance criteria:**

```python
s = NavigationState()
assert s.anchor_date == date.today()
assert s.page_offset == 0
s2 = s.navigate_next()
assert s2.anchor_date == date.today() + timedelta(days=7)
assert s2.page_offset == 1
assert s.navigate_prev() is s   # must not go before today
s3 = s2.navigate_today()
assert s3.anchor_date == date.today() and s3.page_offset == 0
```

### 1.2 - Update `app/calendar/data_builders.py`

`events_range_for_state` no longer uses `state.view` / `state.selected_date`. Rewrite it to return a window covering 30 days starting from `anchor_date` (enough for agenda rendering):

```python
def events_range_for_state(state: NavigationState) -> tuple[datetime, datetime]:
    start = datetime.combine(state.anchor_date, datetime.min.time())
    end = start + timedelta(days=30)
    return start, end
```

Remove `View` import from `data_builders.py`.

**Acceptance criteria:** `events_range_for_state(NavigationState())` returns `(today 00:00, today+30 23:59)`.

### 3.3 - `render()` - Compute Rects and Delegate

```python
def render(self, state: NavigationState, events: list[CalendarEvent]) -> Image.Image:
    W, H = self._size
    palette = get_palette(state.night_mode)
    img = Image.new("RGB", (W, H), palette["BG"])
    draw = ImageDraw.Draw(img)

    weather = WeatherData()  # placeholder - weather provider not implemented in v0.5.0

    if self._layout == "portrait":
        weather_rect   = (0,            0,           W,           BANNER_HEIGHT)
        calendar_rect  = (0,            BANNER_HEIGHT, W,          CALENDAR_HEIGHT)
        agenda_rect    = (0,            BANNER_HEIGHT + CALENDAR_HEIGHT,
                          W,            H - BANNER_HEIGHT - CALENDAR_HEIGHT - FOOTER_HEIGHT)
        footer_rect    = (0,            H - FOOTER_HEIGHT, W,      FOOTER_HEIGHT)
    else:  # landscape
        col_left  = int(W * COL_LEFT_RATIO)
        col_right = W - col_left
        weather_rect   = (0,        0,          col_left,   BANNER_HEIGHT)
        calendar_rect  = (0,        BANNER_HEIGHT, col_left, H - BANNER_HEIGHT - FOOTER_HEIGHT)
        agenda_rect    = (col_left, 0,          col_right,  H - FOOTER_HEIGHT)
        footer_rect    = (0,        H - FOOTER_HEIGHT, W,   FOOTER_HEIGHT)

    self._draw_weather(draw, weather_rect, weather, palette)
    self._draw_mini_calendar(draw, calendar_rect, state, events, palette)
    self._draw_agenda(draw, agenda_rect, state, events, palette)
    self._draw_footer(draw, footer_rect, state, palette)
    return img
```

### 3.4 - `_draw_weather(draw, rect, weather, palette)`

Draw the weather banner within `rect = (x0, y0, w, h)`.

**Content (left to right):**

- **Date:** `f"{_DAY_NAMES_FULL_IT[today.weekday()]}, {today.day} {_MONTH_NAMES_IT[today.month-1]} {today.year}"` - `self._font_display`, `palette["INK"]`, with 12 px left margin from `x0`
- **Temperature + icon (only if `weather.temp_current is not None`):** right-aligned, 12 px right margin - temperature in semibold `self._font_body`, max/min in `self._font_label`, `palette["INK_MUTED"]`
- **Bottom separator:** horizontal line `palette["RULE_STRONG"]`, 2 px thickness, from `(x0, y0 + h - 1)` to `(x0 + w, y0 + h - 1)`

The weather condition icon (Tabler SVG) is not rendered in v0.5.0 - use a simple text fallback if `weather.condition_icon is not None` (e.g. `"☀"` / `"☁"` / `"🌧"` via mapping, using Unicode BMP-compatible characters for IBM Plex Sans), or silently omit the icon.

### 3.5 - `_draw_mini_calendar(draw, rect, state, events, palette)`

Draw the visual monthly calendar inside `rect`. It is not interactive - it shows the current month (`state.anchor_date` month).

Use `_build_month_grid(year, month, events, today)` from `data_builders` to get the grid.

**Internal layout (coordinates relative to `x0, y0`):**

```
month_header_h = 20 px   -> centered text "MAY 2026", uppercase label font
dow_header_h   = 16 px   -> "MON TUE WED THU FRI SAT SUN", label font, COLOR_INK_MUTED
grid_h = h - month_header_h - dow_header_h
n_rows = len(grid_rows)       -> typically 5 or 6
cell_h = grid_h / n_rows
cell_w = w / 7
```

**Cell content:**

- Day number: `self._font_label`, `palette["INK"]`; `palette["INK_FAINT"]` for out-of-month days
- **Today:** filled 16 x 16 px square, `palette["ACCENT"]`; text in `palette["BG"]`
- **Holidays/events:** no indicators in mini-calendar (consistent with design.md: "No event markers in the calendar")

**Bottom separator** (portrait layout only): `palette["RULE_STRONG"]` 1 px line at the bottom of `rect`.

### 3.6 - `_draw_agenda(draw, rect, state, events, palette)`

List events from `state.anchor_date` onward, with `PAGE_DAYS` days per page.

**Event window:** from `state.anchor_date` to `state.anchor_date + timedelta(days=PAGE_DAYS - 1)` (7 days).

**Internal layout:**

```
padding_x = 12 px        # inner horizontal margin
separator_h = 16 px      # date separator row height
event_row_h = 28 px      # event row height (without location)
event_row_loc_h = 42 px  # event row height (with location)
time_col_w = 56 px       # time column (mono font), right-aligned
```

**Date separator:**

```
-- TODAY, SUNDAY 24 MAY ----------------
```

Uppercase text in `self._font_label`, `palette["INK_MUTED"]`; horizontal side lines in `palette["RULE"]`. Today's date uses prefix `"TODAY, "` + weekday name + day + month; subsequent days use weekday name + day + month.

**Event row:**

- Time: `self._font_mono`, `palette["INK_MUTED"]`, fixed width `time_col_w`, right-aligned; `"All day"` in `palette["INK_FAINT"]` for all-day events
- Vertical border: `palette["RULE"]` 1 px line at `x0 + padding_x + time_col_w`
- Title: semibold `self._font_body`, `palette["INK"]`; truncate with `"..."` if it exceeds available width
- Location (if present): `self._font_label`, `palette["INK_MUTED"]`, separate line under the title
- Bottom separator between events: `palette["RULE"]` 1 px line

**Empty list:** centered text `"No appointments"` in `rect`, `self._font_label`, `palette["INK_FAINT"]`.

**Overflow:** if events do not fit in available `rect` space, show the last slot as `"... N more appointments"` (count of remaining events). Do not render beyond `y0 + h`.

**Column separator** (landscape layout only): `palette["RULE_STRONG"]` 1 px line on the left side of `rect` (at `x0`), from top to the footer top edge.

### 3.7 - `_draw_footer(draw, rect, state, palette)`

Footer with navigation buttons on the left and status indicators on the right.

**Top separator:** `palette["RULE"]` 1 px line at top of `rect`.

**Buttons (left to right):** `[ ↑ Up ]  [ ↓ Down ]  [ ← Today ]  [ ☾ Night ]`

- Each button: variable width, 16 px horizontal padding, full `rect` height (40 px)
- Text: `self._font_label`, `palette["INK"]`
- Vertical separators: `palette["RULE"]` 1 px lines between buttons
- Night button is visible only if `config.display.type == "hdmi"` (passed in constructor or checked in `_draw_footer` via `self._display_type`)
- Disabled button color: `palette["INK_FAINT"]` for "Up" when `state.page_offset == 0`

**Status indicators (right side, remaining space):**

- Display type: `"e-ink"` / `"hdmi"` - `self._font_label`, `palette["INK_MUTED"]`
- Layout: `"portrait"` / `"landscape"` - `self._font_label`, `palette["INK_MUTED"]`
- Color mode (HDMI only): `"☀ Day"` / `"☾ Night"` - `self._font_label`, `palette["INK_MUTED"]`
- Current time: `datetime.now().strftime("%H:%M")` - `self._font_mono`, `palette["INK_MUTED"]`

## Phase 4 - HdmiDisplay - pygame rewrite

**Goal:** `display/hdmi.py` replaces the Playwright browser with a `pygame` loop that receives `PIL.Image` from `PillowEinkRenderer`.

*Depends on: Phase 1 (NavigationState), Phase 3 (PillowEinkRenderer).* 

### 4.1 - Rewrite `app/display/hdmi.py`

Remove all Playwright code. `HdmiDisplay` exposes one blocking public method:

```python
class HdmiDisplay:
    def __init__(
        self,
        config: DisplayConfig,
        renderer: PillowEinkRenderer,
        aggregator: CalendarAggregator,
        state_manager: StateManager,
    ) -> None: ...

    def run_blocking(self) -> None:
        """Blocks the calling thread; must run on main thread (macOS SDL)."""
        ...
```

**pygame startup:**

```python
import pygame

pygame.init()
flags = pygame.FULLSCREEN | pygame.NOFRAME if self._config.fullscreen else 0
screen = pygame.display.set_mode(
    (self._config.width, self._config.height), flags
)
pygame.display.set_caption("Family Planner")
```

**Loop (~100 ms per iteration):**

```python
clock = pygame.time.Clock()
last_event_fetch = 0.0
events: list[CalendarEvent] = []

while True:
    # Re-fetch events every refresh_interval seconds
    now = time.monotonic()
    if now - last_event_fetch >= self._config.refresh_interval:
        state = self._state_manager.get()
        start, end = events_range_for_state(state)
        try:
            events = self._aggregator.get_events(start, end)
        except Exception as exc:
            logger.error("HdmiDisplay: event fetch error: %s", exc)
        last_event_fetch = now

    # Rendering
    state = self._state_manager.get()
    try:
        pil_img = self._renderer.render(state, events)
        surface = pygame.image.frombytes(pil_img.tobytes(), pil_img.size, "RGB")
        screen.blit(surface, (0, 0))
        pygame.display.flip()
    except Exception as exc:
        logger.error("HdmiDisplay: render error: %s", exc)

    # Keyboard event handling
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            pygame.quit()
            return
        if event.type == pygame.KEYDOWN:
            _handle_key(event.key, self._state_manager)

    clock.tick(10)  # ~100 ms per frame
```

**Key mapping:**

| pygame key | Action | NavigationState method |
|---|---|---|
| `K_UP` / `K_PAGEUP` | Up / previous page | `navigate_prev()` |
| `K_DOWN` / `K_PAGEDOWN` | Down / next page | `navigate_next()` |
| `K_ESCAPE` | Return to today | `navigate_today()` |
| `K_n` | Toggle night mode | `toggle_night_mode()` |
| `K_q` / `K_F4` | Close application | `pygame.quit(); return` |

`_handle_key` is a module-level function (not a method) for simplicity:

```python
def _handle_key(key: int, state_manager: StateManager) -> None:
    state = state_manager.get()
    new_state: NavigationState | None = None
    if key in (pygame.K_UP, pygame.K_PAGEUP):
        new_state = state.navigate_prev()
    elif key in (pygame.K_DOWN, pygame.K_PAGEDOWN):
        new_state = state.navigate_next()
    elif key == pygame.K_ESCAPE:
        new_state = state.navigate_today()
    elif key == pygame.K_n:
        new_state = state.toggle_night_mode()
    if new_state is not None and new_state is not state:
        state_manager.set(new_state)
```

### 4.2 - Thread Model

`run_blocking()` must be called on the **main thread**. Uvicorn is started in a `threading.Thread(daemon=True)` before calling `run_blocking()`. This is handled in `main.py` (Phase 7).

**Acceptance criteria:**

- `display.type: hdmi`, `fullscreen: false`, `width: 1024`, `height: 600`: a pygame window opens with the rendered Home view
- Arrow keys up/down change agenda page; Escape returns to today; `n` toggles palette
- `q` closes the window and exits cleanly

### 5.1 - Rewrite `app/server/routes/index.py`

Remove: 5-view dispatcher, helpers `_render_view`, `_weekly_view`, `_monthly_view`, `_annual_view`, `_daily_view`, `_detail_view`, `_get_night_mode`, local `_event_to_grid`, local `_build_month_grid`, local `_build_annual_months`, local `_find_event_by_uid`.

New implementation:

```python
import io
from fastapi import APIRouter
from fastapi.requests import Request
from fastapi.responses import StreamingResponse
from fastapi.templating import Jinja2Templates

router = APIRouter()


@router.get("/")
async def index(request: Request):
    """Preview page - auto-refresh calendar image."""
    templates: Jinja2Templates = request.app.state.templates
    return templates.TemplateResponse(
        "index.html",
        {"request": request, "refresh_interval": request.app.state.config.display.refresh_interval},
    )


@router.get("/preview.png")
async def preview_png(request: Request) -> StreamingResponse:
    """Render Home view and return an on-demand PNG."""
    from app.calendar.data_builders import events_range_for_state

    state_manager = request.app.state.state_manager
    aggregator = request.app.state.aggregator
    renderer = request.app.state.renderer

    state = state_manager.get()
    start, end = events_range_for_state(state)
    try:
        events = aggregator.get_events(start, end)
    except Exception as exc:
        logger.error("preview_png: event fetch error: %s", exc)
        events = []

    img = renderer.render(state, events)
    buf = io.BytesIO()
    img.save(buf, format="PNG")
    buf.seek(0)
    return StreamingResponse(buf, media_type="image/png")
```

```python
    renderer: PillowEinkRenderer,
    eink_renderer: EinkRenderer,
    display: EinkDisplay,
    aggregator: CalendarAggregator,
    state_manager: StateManager,
    interval: int,
    stop_event: threading.Event,
) -> None:
    from app.calendar.data_builders import events_range_for_state
    logger.info("E-ink loop started (interval=%ds).", interval)

    while not stop_event.is_set():
        state = state_manager.get()
        start, end = events_range_for_state(state)
        try:
            events = aggregator.get_events(start, end)
            img = renderer.render(state, events)
            processed = eink_renderer.process(img)
            display.push(processed)
        except Exception as exc:
            logger.error("E-ink render/push error: %s", exc)
        stop_event.wait(timeout=interval)

    logger.info("E-ink loop stopped.")
```

## Version Goal

v0.5.0 completes architecture unification by removing Playwright from the runtime and adopting **`PillowEinkRenderer` as the single renderer** for both displays (HDMI and e-ink).

The three critical issues driving this change from v0.4.0:

1. **5-view system removed.** The interface now uses a single Home screen (weather banner · mini-calendar · agenda list · footer). The `View` enum and its navigation hierarchy are removed.
2. **`HdmiDisplay` refactored.** It drops non-headless Chromium: the window is now a `pygame` SDL surface that receives the `PIL.Image` produced by `PillowEinkRenderer` directly, removing the `playwright` dependency for both display types.
3. **`NavigationState` simplified.** Fields `view`, `selected_date`, `selected_event_uid`, `detail_scroll_offset` are replaced by `anchor_date` and `page_offset`; actions `in/out/up/down` become `prev/next/today/night`.

At the end of v0.5.0, the `playwright` binary is no longer a project dependency. `docs/architecture.md` and `docs/design.md` already describe the target for this release; this dev plan documents the migration from current code to that target.

```python
@dataclass(frozen=True)
class NavigationState:
    anchor_date: date = field(default_factory=date.today)
    page_offset: int = 0
    night_mode: bool = False

    def navigate_next(self) -> NavigationState:
        """Advance by PAGE_DAYS days in the agenda list."""
        return replace(
            self,
            anchor_date=self.anchor_date + timedelta(days=PAGE_DAYS),
            page_offset=self.page_offset + 1,
        )

    def navigate_prev(self) -> NavigationState:
        """Go back by PAGE_DAYS days; do not go before today."""
        if self.page_offset <= 0:
            return self
        return replace(
            self,
            anchor_date=self.anchor_date - timedelta(days=PAGE_DAYS),
            page_offset=self.page_offset - 1,
        )

    def navigate_today(self) -> NavigationState:
        """Reset anchor_date to today and clear page_offset."""
        return replace(self, anchor_date=date.today(), page_offset=0)

    def toggle_night_mode(self) -> NavigationState:
        """Toggle night mode (HDMI only)."""
        return replace(self, night_mode=not self.night_mode)
```

```python
def render(self, state: NavigationState, events: list[CalendarEvent]) -> Image.Image:
    W, H = self._size
    palette = get_palette(state.night_mode)
    img = Image.new("RGB", (W, H), palette["BG"])
    draw = ImageDraw.Draw(img)

    weather = WeatherData()  # placeholder - weather provider is not implemented in v0.5.0

    if self._layout == "portrait":
        weather_rect   = (0,            0,           W,           BANNER_HEIGHT)
        calendar_rect  = (0,            BANNER_HEIGHT, W,          CALENDAR_HEIGHT)
        agenda_rect    = (0,            BANNER_HEIGHT + CALENDAR_HEIGHT,
                          W,            H - BANNER_HEIGHT - CALENDAR_HEIGHT - FOOTER_HEIGHT)
        footer_rect    = (0,            H - FOOTER_HEIGHT, W,      FOOTER_HEIGHT)
    else:  # landscape
        col_left  = int(W * COL_LEFT_RATIO)
        col_right = W - col_left
        weather_rect   = (0,        0,          col_left,   BANNER_HEIGHT)
        calendar_rect  = (0,        BANNER_HEIGHT, col_left, H - BANNER_HEIGHT - FOOTER_HEIGHT)
        agenda_rect    = (col_left, 0,          col_right,  H - FOOTER_HEIGHT)
        footer_rect    = (0,        H - FOOTER_HEIGHT, W,   FOOTER_HEIGHT)

    self._draw_weather(draw, weather_rect, weather, palette)
    self._draw_mini_calendar(draw, calendar_rect, state, events, palette)
    self._draw_agenda(draw, agenda_rect, state, events, palette)
```

### 3.5 — `_draw_mini_calendar(draw, rect, state, events, palette)`

**Internal layout (coordinates relative to `x0, y0`):**

### 3.6 — `_draw_agenda(draw, rect, state, events, palette)`

Agenda list from `state.anchor_date` onward, `PAGE_DAYS` per page.

**Event window:** from `state.anchor_date` to `state.anchor_date + timedelta(days=PAGE_DAYS - 1)` (7 days).

**Internal layout:**

```
padding_x = 12 px        # internal horizontal margin
separator_h = 16 px      # date separator row height
event_row_h = 28 px      # event row height (without location)
event_row_loc_h = 42 px  # event row height (with location)
time_col_w = 56 px       # time column (font_mono), right-aligned
```

**Date separator:**

```
-- TODAY, SUNDAY 24 MAY ----------------
```

Uppercase text in `self._font_label`, `palette["INK_MUTED"]`; side horizontal lines in `palette["RULE"]`. Today's date uses prefix `"TODAY, "` + weekday + day + month; following dates use weekday + day + month only.

**Event row:**

- Time: `self._font_mono`, `palette["INK_MUTED"]`, fixed width `time_col_w`, right-aligned; `"All day"` in `palette["INK_FAINT"]` for all-day events
- Vertical divider: 1 px line in `palette["RULE"]` at `x0 + padding_x + time_col_w`
- Title: `self._font_body` semibold, `palette["INK"]`; truncated with `"..."` if too wide
- Location (if present): `self._font_label`, `palette["INK_MUTED"]`, separate line below title
- Bottom separator between events: 1 px `palette["RULE"]` line

**Empty list:** centered text `"No appointments"` in `rect`, `self._font_label`, `palette["INK_FAINT"]`.

**Overflow:** if events exceed available `rect` space, use last slot for `"... N more appointments"` (count remaining events). Do not render beyond `y0 + h`.

**Column separator** (landscape only): 1 px `palette["RULE_STRONG"]` line on left side of `rect` (at `x0`), from top to footer top edge.

### 3.7 — `_draw_footer(draw, rect, state, palette)`

Footer with navigation buttons on the left and status indicators on the right.

**Top separator:** 1 px `palette["RULE"]` line at top of `rect`.

**Buttons (left to right):** `[ Up ]  [ Down ]  [ Today ]  [ Night ]`

- Each button: variable width, 16 px horizontal padding, full `rect` height (40 px)
- Text: `self._font_label`, `palette["INK"]`
- Vertical separators: 1 px `palette["RULE"]` lines between buttons
- Night button is visible only if `config.display.type == "hdmi"` (passed to constructor or checked in `_draw_footer` via `self._display_type`)
- Disabled buttons: `palette["INK_FAINT"]` when `state.page_offset == 0` for "Up"

**Status indicators (right, remaining space):**

- Display type: `"e-ink"` / `"hdmi"` - `self._font_label`, `palette["INK_MUTED"]`
- Layout: `"portrait"` / `"landscape"` - `self._font_label`, `palette["INK_MUTED"]`
- Color mode (HDMI only): `"Day"` / `"Night"` - `self._font_label`, `palette["INK_MUTED"]`
- Current time: `datetime.now().strftime("%H:%M")` - `self._font_mono`, `palette["INK_MUTED"]`

**Goal:** `display/hdmi.py` replaces the Playwright browser with a `pygame` loop that receives the `PIL.Image` from `PillowEinkRenderer`.

*Depends on: Phase 1 (NavigationState), Phase 3 (PillowEinkRenderer).*

### 4.1 — Rewrite `app/display/hdmi.py`

Delete all Playwright code. `HdmiDisplay` exposes one public blocking method:

```python
class HdmiDisplay:
    def __init__(
        self,
        config: DisplayConfig,
        renderer: PillowEinkRenderer,
        aggregator: CalendarAggregator,
        state_manager: StateManager,
    ) -> None: ...

    def run_blocking(self) -> None:
        """Blocks caller thread; must run on main thread (macOS SDL)."""
        ...
```

**pygame initialization:**

```python
import pygame

pygame.init()
flags = pygame.FULLSCREEN | pygame.NOFRAME if self._config.fullscreen else 0
screen = pygame.display.set_mode(
    (self._config.width, self._config.height), flags
)
pygame.display.set_caption("Family Planner")
```

**Loop (~100 ms per iteration):**

```python
clock = pygame.time.Clock()
last_event_fetch = 0.0
events: list[CalendarEvent] = []

while True:
    # Re-fetch events every refresh_interval seconds
    now = time.monotonic()
    if now - last_event_fetch >= self._config.refresh_interval:
        state = self._state_manager.get()
        start, end = events_range_for_state(state)
        try:
            events = self._aggregator.get_events(start, end)
        except Exception as exc:
            logger.error("HdmiDisplay: event fetch error: %s", exc)
        last_event_fetch = now

    # Rendering
    state = self._state_manager.get()
    try:
        pil_img = self._renderer.render(state, events)
        surface = pygame.image.frombytes(pil_img.tobytes(), pil_img.size, "RGB")
        screen.blit(surface, (0, 0))
        pygame.display.flip()
    except Exception as exc:
        logger.error("HdmiDisplay: render error: %s", exc)

    # Keyboard event handling
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            pygame.quit()
            return
        if event.type == pygame.KEYDOWN:
            _handle_key(event.key, self._state_manager)

    clock.tick(10)  # ~100 ms per frame
```

**Key mapping:**

| pygame key | Action | NavigationState method |
|---|---|---|
| `K_UP` / `K_PAGEUP` | Up / previous page | `navigate_prev()` |
| `K_DOWN` / `K_PAGEDOWN` | Down / next page | `navigate_next()` |
| `K_ESCAPE` | Back to today | `navigate_today()` |
| `K_n` | Toggle night mode | `toggle_night_mode()` |
| `K_q` / `K_F4` | Close app | `pygame.quit(); return` |

`_handle_key` is a module-level function (not a method) for simplicity:

```python
def _handle_key(key: int, state_manager: StateManager) -> None:
    state = state_manager.get()
    new_state: NavigationState | None = None
    if key in (pygame.K_UP, pygame.K_PAGEUP):
        new_state = state.navigate_prev()
    elif key in (pygame.K_DOWN, pygame.K_PAGEDOWN):
        new_state = state.navigate_next()
    elif key == pygame.K_ESCAPE:
        new_state = state.navigate_today()
    elif key == pygame.K_n:
        new_state = state.toggle_night_mode()
    if new_state is not None and new_state is not state:
        state_manager.set(new_state)
```

### 4.2 — Thread model

`run_blocking()` must be called on the **main thread**. Uvicorn is started in a `threading.Thread(daemon=True)` before calling `run_blocking()`. This is handled in `main.py` (Phase 7).

**Acceptance criteria:**

- `display.type: hdmi`, `fullscreen: false`, `width: 1024`, `height: 600`: a pygame window opens with Home view rendered
- Up/Down arrow keys change agenda page; Esc returns to today; `n` toggles palette
- `q` closes the window and terminates the process cleanly

```python
def _eink_loop(
    renderer: PillowEinkRenderer,
    eink_renderer: EinkRenderer,
    display: EinkDisplay,
    aggregator: CalendarAggregator,
    state_manager: StateManager,
    interval: int,
    stop_event: threading.Event,
) -> None:
    from app.calendar.data_builders import events_range_for_state
    logger.info("E-ink loop started (interval=%ds).", interval)

    while not stop_event.is_set():
        state = state_manager.get()
        start, end = events_range_for_state(state)
        try:
            events = aggregator.get_events(start, end)
            img = renderer.render(state, events)
            processed = eink_renderer.process(img)
            display.push(processed)
        except Exception as exc:
            logger.error("E-ink render/push error: %s", exc)
        stop_event.wait(timeout=interval)

    logger.info("E-ink loop stopped.")
```
