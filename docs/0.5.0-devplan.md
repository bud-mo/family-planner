# Piano di Sviluppo — Family Planner v0.5.0

> Versione: 0.5.0
> Data: 24 maggio 2026
> Riferimenti: `docs/architecture.md`, `docs/design.md`, `docs/0.4.0-devplan.md`

---

## Obiettivo della versione

v0.5.0 completa l'unificazione dell'architettura eliminando Playwright dal processo e adottando **`PillowEinkRenderer` come renderer unico** per entrambi i display (HDMI ed e-ink).

Le tre criticità che motivano il cambiamento rispetto a v0.4.0:

1. **Sistema a 5 viste abbandonato.** L'interfaccia adotta una singola schermata Home (banner meteo · mini-calendario · lista appuntamenti · footer). Il `View` enum e la gerarchia di navigazione associata sono rimossi.
2. **`HdmiDisplay` refactored.** Abbandona il browser Chromium non-headless: la finestra è ora una `pygame` SDL che riceve direttamente il `PIL.Image` prodotto da `PillowEinkRenderer`, eliminando la dipendenza da `playwright` per entrambi i tipi di display.
3. **`NavigationState` semplificato.** I campi `view`, `selected_date`, `selected_event_uid`, `detail_scroll_offset` sono sostituiti da `anchor_date` e `page_offset`; le azioni `in/out/up/down` diventano `prev/next/today/night`.

Al termine di v0.5.0 il binario `playwright` non è più una dipendenza del progetto. `docs/architecture.md` e `docs/design.md` descrivono già il target di questa versione; il devplan documenta la migrazione dal codice corrente a quella specifica.

## Vincoli invarianti

I vincoli delle versioni precedenti rimangono validi. In aggiunta, per v0.5.0:

- `PillowEinkRenderer` è la **fonte unica** di rendering — `playwright` non è mai avviato, né importato in modalità normale
- `HdmiDisplay.run_blocking()` gira sul **main thread**; Uvicorn gira in un `threading.Thread(daemon=True)` separato
- La struttura di `NavigationState` è sempre immutabile; i metodi `navigate_*` restituiscono nuove istanze
- `StateManager` è la **sola** fonte di verità per `NavigationState` — nessun altro oggetto possiede o copia lo stato in modo autonomo
- `render()` è il **solo** punto dove si calcolano i `Rect` di layout — i metodi `_draw_*` ricevono il `Rect` come parametro e non leggono costanti globali di layout
- `WeatherData` è un placeholder in v0.5.0 — tutti i campi sono `None`; il banner meteo mostra solo la data odierna
- Le costanti `_GRID_*` e le funzioni `_event_to_grid`, `_build_annual_months`, `_find_event_by_uid` restano in `data_builders.py` fino alla fase di cleanup (Fase 8) per non bloccare lo sviluppo parallelo

## Fase 1 — NavigationState

**Goal:** `NavigationState` usa `anchor_date` e `page_offset` invece di `view` / `selected_date` / `selected_event_uid` / `detail_scroll_offset`. I metodi di navigazione diventano `navigate_prev`, `navigate_next`, `navigate_today`, `toggle_night_mode`.

*Nessuna dipendenza — questa fase è il prerequisito per Fase 3, 5, 6.*

### 1.1 — Riscrivere `app/renderer/state.py`

Rimuovere:
- `View` enum e tutti i suoi valori
- Campi `view`, `selected_date`, `selected_event_uid`, `detail_scroll_offset`
- Metodi `navigate_escape`, `navigate_enter`, `navigate_up`, `navigate_down`
- Helper `_events_for_date`, `_select_adjacent_event`
- Import di `TYPE_CHECKING` / `CalendarEvent` (non più necessari)

Nuova struttura del dataclass:

```python
@dataclass(frozen=True)
class NavigationState:
    anchor_date: date = field(default_factory=date.today)
    page_offset: int = 0
    night_mode: bool = False

    def navigate_next(self) -> NavigationState:
        """Avanza di PAGE_DAYS giorni nella lista appuntamenti."""
        return replace(
            self,
            anchor_date=self.anchor_date + timedelta(days=PAGE_DAYS),
            page_offset=self.page_offset + 1,
        )

    def navigate_prev(self) -> NavigationState:
        """Retrocede di PAGE_DAYS giorni; non va prima di oggi."""
        if self.page_offset <= 0:
            return self
        return replace(
            self,
            anchor_date=self.anchor_date - timedelta(days=PAGE_DAYS),
            page_offset=self.page_offset - 1,
        )

    def navigate_today(self) -> NavigationState:
        """Reimposta anchor_date a oggi e azzera page_offset."""
        return replace(self, anchor_date=date.today(), page_offset=0)

    def toggle_night_mode(self) -> NavigationState:
        """Toggle modalità notte (solo HDMI)."""
        return replace(self, night_mode=not self.night_mode)
```

Aggiungere la costante di modulo:

```python
PAGE_DAYS: int = 7   # giorni di avanzamento per navigate_next/navigate_prev
```

**Criteri di accettazione:**

```python
s = NavigationState()
assert s.anchor_date == date.today()
assert s.page_offset == 0
s2 = s.navigate_next()
assert s2.anchor_date == date.today() + timedelta(days=7)
assert s2.page_offset == 1
assert s.navigate_prev() is s   # non va prima di oggi
s3 = s2.navigate_today()
assert s3.anchor_date == date.today() and s3.page_offset == 0
```

```python

    W, H = self._size
    palette = get_palette(state.night_mode)
    img = Image.new("RGB", (W, H), palette["BG"])
    draw = ImageDraw.Draw(img)

    weather = WeatherData()  # placeholder — provider meteo non implementato in v0.5.0

        calendar_rect  = (0,        BANNER_HEIGHT, col_left, H - BANNER_HEIGHT - FOOTER_HEIGHT)
```

## Fase 4 — HdmiDisplay — rewrite pygame

**Goal:** `display/hdmi.py` sostituisce il browser Playwright con un loop `pygame` che riceve il `PIL.Image` da `PillowEinkRenderer`.

*Dipende da: Fase 1 (NavigationState), Fase 3 (PillowEinkRenderer).*

### 4.1 — Riscrivere `app/display/hdmi.py`

Eliminare tutto il codice Playwright. La classe `HdmiDisplay` espone un unico metodo pubblico bloccante:

```python
class HdmiDisplay:
    def __init__(
        self,
        config: DisplayConfig,
        renderer: PillowEinkRenderer,
        aggregator: CalendarAggregator,
        state_manager: StateManager,
    ) -> None: ...

    def run_blocking(self) -> None:
        """Blocca il thread chiamante; deve girare sul main thread (macOS SDL)."""
        ...
```

**Avvio pygame:**

```python
import pygame

pygame.init()
flags = pygame.FULLSCREEN | pygame.NOFRAME if self._config.fullscreen else 0
screen = pygame.display.set_mode(
    (self._config.width, self._config.height), flags
)
pygame.display.set_caption("Family Planner")
```

**Loop (~100 ms per iterazione):**

```python
clock = pygame.time.Clock()
last_event_fetch = 0.0
events: list[CalendarEvent] = []

while True:
    # Riacquisto eventi ogni refresh_interval secondi
    now = time.monotonic()
    if now - last_event_fetch >= self._config.refresh_interval:
        state = self._state_manager.get()
        start, end = events_range_for_state(state)
        try:
            events = self._aggregator.get_events(start, end)
        except Exception as exc:
            logger.error("HdmiDisplay: event fetch error: %s", exc)
        last_event_fetch = now

    # Rendering
    state = self._state_manager.get()
    try:
        pil_img = self._renderer.render(state, events)
        surface = pygame.image.frombytes(pil_img.tobytes(), pil_img.size, "RGB")
        screen.blit(surface, (0, 0))
        pygame.display.flip()
    except Exception as exc:
        logger.error("HdmiDisplay: render error: %s", exc)

    # Gestione eventi tastiera
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            pygame.quit()
            return
        if event.type == pygame.KEYDOWN:
            _handle_key(event.key, self._state_manager)

    clock.tick(10)  # ~100 ms per frame
```

**Mapping tasti:**

| Tasto pygame | Azione | Metodo NavigationState |
|---|---|---|
| `K_UP` / `K_PAGEUP` | Su / pagina precedente | `navigate_prev()` |
| `K_DOWN` / `K_PAGEDOWN` | Giù / pagina successiva | `navigate_next()` |
| `K_ESCAPE` | Ritorna a oggi | `navigate_today()` |
| `K_n` | Toggle modalità notte | `toggle_night_mode()` |
| `K_q` / `K_F4` | Chiudi applicazione | `pygame.quit(); return` |

`_handle_key` è una funzione di modulo (non metodo) per semplicità:

```python
def _handle_key(key: int, state_manager: StateManager) -> None:
    state = state_manager.get()
    new_state: NavigationState | None = None
    if key in (pygame.K_UP, pygame.K_PAGEUP):
        new_state = state.navigate_prev()
    elif key in (pygame.K_DOWN, pygame.K_PAGEDOWN):
        new_state = state.navigate_next()
    elif key == pygame.K_ESCAPE:
        new_state = state.navigate_today()
    elif key == pygame.K_n:
        new_state = state.toggle_night_mode()
    if new_state is not None and new_state is not state:
        state_manager.set(new_state)
```

### 4.2 — Thread model

`run_blocking()` deve essere chiamato dal **main thread**. Uvicorn viene avviato in un `threading.Thread(daemon=True)` prima della chiamata a `run_blocking()`. Questo è gestito in `main.py` (Fase 7).

**Criteri di accettazione:**

- `display.type: hdmi`, `fullscreen: false`, `width: 1024`, `height: 600`: si apre una finestra pygame con la Home renderizzata
- I tasti freccia ↑/↓ cambiano la pagina agenda; Esc torna a oggi; `n` inverte la palette

Nuova implementazione:

```python
import io
from fastapi import APIRouter
from fastapi.requests import Request
from fastapi.responses import StreamingResponse
from fastapi.templating import Jinja2Templates

router = APIRouter()


@router.get("/")
async def index(request: Request):
    """Pagina di anteprima — auto-refresh dell'immagine calendario."""
    templates: Jinja2Templates = request.app.state.templates
    return templates.TemplateResponse(
        "index.html",
        {"request": request, "refresh_interval": request.app.state.config.display.refresh_interval},
    )


@router.get("/preview.png")
async def preview_png(request: Request) -> StreamingResponse:
    """Renderizza la Home view e restituisce un PNG on-demand."""
    from app.calendar.data_builders import events_range_for_state

    state_manager = request.app.state.state_manager
    aggregator = request.app.state.aggregator
    renderer = request.app.state.renderer

    state = state_manager.get()
    start, end = events_range_for_state(state)
    try:
        events = aggregator.get_events(start, end)
    except Exception as exc:
        logger.error("preview_png: event fetch error: %s", exc)
        events = []

    img = renderer.render(state, events)
    buf = io.BytesIO()
    img.save(buf, format="PNG")
    buf.seek(0)
    return StreamingResponse(buf, media_type="image/png")
```

```python
def _eink_loop(
    renderer: PillowEinkRenderer,
    eink_renderer: EinkRenderer,
    display: EinkDisplay,
    aggregator: CalendarAggregator,
    state_manager: StateManager,
    interval: int,
    stop_event: threading.Event,
) -> None:
    from app.calendar.data_builders import events_range_for_state
    logger.info("E-ink loop avviato (interval=%ds).", interval)

    while not stop_event.is_set():
        state = state_manager.get()
        start, end = events_range_for_state(state)
        try:
            events = aggregator.get_events(start, end)
            img = renderer.render(state, events)
            processed = eink_renderer.process(img)
            display.push(processed)
        except Exception as exc:
            logger.error("E-ink render/push error: %s", exc)
        stop_event.wait(timeout=interval)

    logger.info("E-ink loop fermato.")
```
